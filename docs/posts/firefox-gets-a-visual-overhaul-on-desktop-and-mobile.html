Firefox Gets a Visual Overhaul on Desktop and Mobile

Mozilla has pushed a significant visual refresh to Firefox across desktop and mobile platforms. The update is live now, and it touches enough of the interface that returning users will notice it immediately.

Compact Mode Is Back

One of the most welcomed changes: compact mode has returned. Mozilla quietly killed it a few years back, and it became one of the more vocal complaints from power users who preferred a denser UI with more room for actual content. It's back, and that alone will pull some users out of their workarounds.

Theme Picker Joins the Mix

The redesign also introduces a built-in theme picker, giving users a more accessible way to customize the browser's appearance without digging through add-ons or about:config tweaks. It's the kind of feature that should have been front-and-center for a while — Firefox has always had strong customization bones, and this makes them easier to reach.

What the Redesign Looks Like in Practice

  • Cleaner tab strip with updated spacing and contrast
  • Refreshed toolbar icons that feel more consistent across platforms
  • Mobile gets the same design language, not just a port-over afterthought
  • Theme picker accessible directly from the main menu

The mobile update is worth calling out specifically. Too often, browser redesigns treat the desktop as the primary canvas and mobile as a secondary concern. Here, Mozilla appears to have applied the new visual language consistently, which matters as more browsing shifts to phones.

Why This Matters

Firefox's market share has been under pressure for years. Chrome dominates, and even Safari has a stronger foothold on Apple hardware than Firefox does. A visual refresh won't flip those numbers on its own, but it signals that Mozilla is still investing in the product as a daily driver — not just as a privacy-focused alternative you install and forget.

The compact mode return, in particular, shows Mozilla is listening to its existing user base rather than chasing new users at the expense of the loyalists who stuck around.

The update is rolling out now. If you're already on Firefox, check for updates — you may already have it. Full coverage of the launch originally reported by Engadget.
